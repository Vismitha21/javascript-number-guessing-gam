# javascript-number-guessing-gam
A simple JavaScript number guessing game where the user sets a maximum number and tries to guess the randomly generated number. The game provides feedback for incorrect guesses and allows the user to quit anytime.

A simple console-based number guessing game built with JavaScript.

The user enters a maximum number, and the program generates a random number within that range. The user keeps guessing until they find the correct number or choose to quit.

### Concepts Used
JavaScript, `Math.random()`, `Math.floor()`, loops, conditions, `prompt()`, and `console.log()`.
